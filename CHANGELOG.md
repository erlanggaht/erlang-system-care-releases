# Changelog

Release notes for Erlang System Care.

## 1.0.0

Initial release for Windows x64.

### Features

- PC overview with quick shutdown, lock, and sleep actions, including a cancellable countdown.
- Device information covering the operating system, CPU, RAM, graphics, disks, network, battery, temperature sensors, and USB devices where available.
- CPU and RAM usage charts, system uptime, and battery information.
- Running application and process lists with search and permitted process termination.
- Cleanup previews for temporary files, Recycle Bin contents, browser data, and crash dumps.
- Cleanup history.
- Scheduled shutdown, lock, and sleep using a countdown or a specific time.
- Windows notifications before scheduled actions, with options to postpone or cancel.
- Schedule history and restoration when the application reopens.
- Customizable work, gaming, and night profiles with power plans, applications, and timer actions.
- Shortcuts to common Windows tools.
- Activity logs with an option to clear history.
- English and Indonesian interface languages.
- Light and dark themes.
- Reduced animation preference.
- Option to launch with Windows.
- System tray access for reopening the application, managing active schedules, and quitting.
