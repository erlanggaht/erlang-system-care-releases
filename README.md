# Erlang System Care

Maintain your PC with ease.

Erlang System Care is a Windows desktop application for monitoring your PC, cleaning unnecessary files, and managing everyday system tasks.

This repository distributes application releases. Source code is available on [GitLab](https://gitlab.com/erlanggaht93/erlang-control-panel-electron).

## Download

Visit the [Releases page](https://github.com/erlanggaht/erlang-system-care-releases/releases) and choose a package:

| Package          | Description                                         |
| ---------------- | --------------------------------------------------- |
| Installer `.exe` | Install the application using the setup wizard.     |
| Portable `.exe`  | Run the application without installation.           |
| Archive `.rar`   | Extract the package before running the application. |

Platform: **Windows, 64-bit (x64)**.

## Getting started

### Installer

1. Download the file ending in `-Setup.exe`.
2. Double-click it and follow the setup wizard.
3. Choose an installation folder and complete the installation.
4. Open **Erlang System Care** from the Start menu or its shortcut.

### Portable

1. Download the file ending in `-Portable.exe`.
2. Save it in a folder of your choice.
3. Double-click the file to open the application.

### RAR archive

1. Download the `.rar` package.
2. Extract all files using an archive tool that supports RAR.
3. Keep the extracted files together.
4. Open `Erlang System Care.exe`. If the archive contains an installer instead, follow the installer instructions above.

Closing the application window keeps it running in the system tray. Click its tray icon to reopen it, or use the tray menu to quit.

## Key features

- **System monitoring:** View CPU and RAM usage, find running applications, and end permitted processes.
- **Device information:** Explore hardware and system details, including battery, sensors, and USB devices where available.
- **Cleaner:** Preview and clean temporary files, Recycle Bin contents, browser data, and crash dumps.
- **Power scheduler:** Schedule shutdown, lock, or sleep with options to postpone or cancel.
- **Activity profiles:** Customize work, gaming, and night profiles.
- **Windows shortcuts:** Access common Windows tools from one place.
- **Activity history:** Review application activity and cleanup results.
- **Preferences:** Choose English or Indonesian, light or dark themes, reduced animations, and startup behavior.
